В сборках использовался исходный код из репозитория https://github.com/xmrig/xmrig/releases файлы Source code (zip).
Необходимо использовать 64-разрядную версию Windows (x64) 

Для майнига или тестирования xmrig.exe рекомендую отключить службы:
Microsoft Edge Elevation Service,
Microsoft Edge Update Service (edgeupdate)
Microsoft Edge Update Service (edgeupdatem) 
System Guard (Брокер мониторинга среды выполнения System Guard)
Microsoft Defender,
Обновления Windows.

Это не значит, что нужно доверять любым файлам, скачанным с интернета ! 
Всё, что попадает к вам на ПК, должно проверяться реальным профессиональным антивирусом !
Но именно для майнинга перечисленные службы могут сильно влиять на работу программы xmrig.exe и соответственно, на ваш хешрейт !

Все файлы были протестированы на Intel Core i5-10500, Intel Xeon E5-2680 v4 и Intel Xeon E5-2690 v4; также они будут работать на процессорах Ryzen.
Особой разницы между версиями 6.24.0 6.25.0 6.25.0 нет в новых версиях добавлена поддержка самых новых процессоров.
Ваш хешрейт будет зависеть от загруженности вашей Windows фоновыми задачами.

Представлены три основных варианта сборок, касающихся использования пакета зависимостей (Deps) и инструментов компиляции:
в.1) При сборке использовался пакет зависимостей "Deps-v5.0" для "MINGW64" и "Deps-v25.06.16" для "UCRT64"
в.2) При сборке НЕ использовался пакет зависимостей "Deps" для работы программы добавлены необходимые .dll файлы.  Рекомендую к тестированию.
в.3) При сборке использовались стандартные(родные) средства cmd.exe и PowerShell. По сути, это нативная сборка на MSVC (cl.exe) в среде Visual Studio 2022.  Рекомендую к тестированию.

------ Условно старая среда Mingw64 ----------------------------------------------------------------------------------------------------------------
Mingw64.Make.deps       - среда выполнения MSYS2 MINGW64, генератор GCC "Unix Makefiles", с инструкциями deps5.0
Mingw64.Make.no_deps - среда выполнения MSYS2 MINGW64, генератор GCC "Unix Makefiles", без инструкций deps + Files .dll
Mingw64.Ninja.deps       - среда выполнения MSYS2 MINGW64, генератор GCC "Ninja", с инструкциями deps5.0
Mingw64.Ninja.no_deps - среда выполнения MSYS2 MINGW64, генератор GCC "Ninja", без инструкций deps + Files .dll

------- Стандартная среда виндовс ------------------------------------------------------------------------------------------------------------------
Win64.cmd        - среда выполнения cmd.exe, MSVC (cl.exe) "Visual Studio 2022", с инструкциями deps25.06.16
Win64.PShell     - среда выполнения PowerShell, MSVC (cl.exe) "Visual Studio 2022", с инструкциями deps25.06.16

------- Новая среда на данный момент Ucrt64 --------------------------------------------------------------------------------------------------------
Ucrt64.Make.deps        - среда выполнения MSYS2 UCRT64 генератор GCC "Unix Makefiles", с инструкциями deps25.06.16
Ucrt64.Make.no_deps  - среда выполнения MSYS2 UCRT64 генератор GCC "Unix Makefiles", без инструкций deps + Files .dll
Ucrt64.Ninja.deps        - среда выполнения MSYS2 UCRT64 генератор GCC "Ninja", с инструкциями deps25.06.16
Ucrt64.Ninja.no_deps  - среда выполнения MSYS2 UCRT64 генератор GCC "Ninja", без инструкций deps + Files .dll

 Файл конфигураций config.json в каждой сборке максимально настроен, протестирован 257-раз и готов к работе ! 
 Без точного проверенного понимания что делаете, параметры config.json не меняйте и не ведитесь на советы от ИИ врёт и не краснеет !

 1. Пропишите свой пул "url": "pool.supportxmr.com:5555", (или используйте указанный), 
 2. Укажите свой номер кошелька "user": "YOUR_WALLET_ADDRESS",   вот такого вида   "9E4bk0pyhyksWeHmUY8RdfRFEY7BkdczHu******************h9yksW34eHmUY9R7dmRkY7Bk"
 3. Можно указать "pass": "Miners_name",  имя вашего майнера(шахтёра)  например "DeepCool" или "Das _ist_Fantastisch" этих трёх настроек будет достаточно для запуска и работы программы.

 При первом запуске подождите 30 сек. закройте окно программы и перезагрузите ПК повторите запуск, это нужно для применения настроек "HUGE PAGES"  permission granted - должно быть зелёным.
 Настройка "log-file": "logi/log.txt", указывает на папку logi в ней при старте майнинга будет создан текстовый документ log.txt в котором можно увидеть весь процесс работы xmrig.exe что очень удобно для анализа.

*Если вы в чём-то сомневаетесь, не уверены или у вас есть смутные сомнения (а также если вы являетесь Свидетелем Иеговы), не используйте эти сборки. Удалите все файлы, сядьте, закройте глаза и представьте, что ничего не было.
